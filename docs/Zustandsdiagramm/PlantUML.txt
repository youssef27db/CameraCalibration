@startuml
title Zustandsdiagramm: Datengetriebene Kalibrierung eines LFC-Systems

[*] --> Uncalibrated

state "Initial Reference Calibration" as InitCalib {
  [*] --> CapturingTargets

  CapturingTargets : Checkerboard-Aufnahmen erfassen
  CapturingTargets --> EstimatingParameters : Bilder vollständig

  EstimatingParameters : Intrinsics & Extrinsics schätzen\n(OpenCV, optional BA)
  EstimatingParameters --> BaselineCreated

  BaselineCreated : HealthScore berechnen\nBaseline.json erzeugen
}

Uncalibrated --> InitCalib : runInitialCalibration()
InitCalib --> Operational : Baseline vorhanden

state Operational {

  [*] --> SchedulerIdle

  SchedulerIdle : Periodischer Scheduler\n(z.B. alle 5 Minuten)
  SchedulerIdle --> PrepareImageset : cycleStart()

  PrepareImageset : Prüfe LiFCal_Data\n(focus/depth)
  PrepareImageset --> RunLiFCal : Daten vorhanden
  PrepareImageset --> RunImageSetCreation : Daten fehlen

  RunImageSetCreation : run_imageset_creation.py
  RunImageSetCreation --> RunLiFCal

  RunLiFCal : LiFCal-Rekalibrierung\n(pro Kamera)
  RunLiFCal --> CombineResults

  CombineResults : parameters.json → combined.json
  CombineResults --> EvaluateHealth

  EvaluateHealth : LiFCal-HealthScore\nberechnen

  ' Verbesserung → neue Baseline
  EvaluateHealth --> UpdateBaseline : [Score_neu > Score_baseline]

  ' Keine Verbesserung → Baseline bleibt
  EvaluateHealth --> KeepBaseline : [Score_neu ≤ Score_baseline]

  UpdateBaseline : baseline.json aktualisieren
  UpdateBaseline --> SchedulerIdle

  KeepBaseline : baseline unverändert
  KeepBaseline --> SchedulerIdle
}

Operational --> [*]
@enduml
