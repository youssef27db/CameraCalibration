\section*{Use Case: Cross-Shaped Camera Array 
\newline
[Center + North/East/South/West]}

\subsection*{Phase 1 — Initial Reference Calibration (once)}
\begin{itemize}
  \item \textbf{Target-based, OpenCV:}
  Perform a one-time checkerboard-based calibration to estimate intrinsic and extrinsic parameters
  for all cameras of the cross-shaped array.

  \item \textbf{Optional refinement:}
  Apply an optional global refinement (bundle adjustment) to improve consistency of the estimated parameters.

  \item \textbf{Baseline creation:}
  Compute a global health score for the initial calibration and store the result as \texttt{baseline.json}.
  This baseline represents the known-good reference calibration for later recalibration decisions.

  \item \textbf{Logging:}
  Store the full initial calibration as a timestamped JSON file and write a summary line to \texttt{calibration.log}.
\end{itemize}

\subsection*{Phase 2 — Automated Recalibration Attempts (periodic scheduler)}
\begin{itemize}
  \item \textbf{Trigger:}
  A fixed time interval (e.g.\ every 5 minutes) executes an automated recalibration cycle.

  \item \textbf{Conditional data preparation (optional):}
  If LiFCal-compatible data (\texttt{LiFCal\_Data} with focus and depth directories) is already present and complete,
  the system reuses it. Otherwise, the system runs \texttt{run\_imageset\_creation.py} to generate the required inputs
  (focus images and virtual depth).

  \item \textbf{LiFCal recalibration run:}
  Execute \texttt{run\_LiFCal\_calibration.py} which:
  \begin{itemize}
    \item runs LiFCal recalibration for each camera (Center, Up/Down/Left/Right),
    \item exports per-camera parameter JSON files (\texttt{parameters.json}),
    \item creates a combined multi-camera result (\texttt{combined.json}).
  \end{itemize}

  \item \textbf{Logging and traceability:}
  Store the combined LiFCal result as a timestamped JSON file in \texttt{/data/baseline}
  and append all relevant run information to \texttt{calibration.log}.
\end{itemize}

\subsection*{Phase 3 — Health Evaluation and Baseline Update Rule (commit decision)}
\begin{itemize}
  \item \textbf{Health score (LiFCal):}
  Compute a single global health score (range $[0,100]$) from the LiFCal combined parameter result (\texttt{combined.json}).
  The score represents the calibration quality of the complete camera array for this recalibration cycle.

  \item \textbf{Comparison against baseline:}
  Compare the new LiFCal health score with the health score stored in the baseline calibration.

  \item \textbf{Acceptance rule (commit):}
  If the new health score is strictly higher than the baseline score, replace \texttt{baseline.json}
  with the new combined calibration result. Otherwise, keep the existing baseline unchanged.

  \item \textbf{Continuous improvement loop:}
  The scheduler repeats the recalibration cycle periodically. Over time, improved recalibration runs can update the baseline,
  enabling a data-driven refinement process without manual intervention.
\end{itemize}
