\section*{Use Case: Cross-Shaped Camera Array 
\newline
[Center + North/East/South/West]}


\subsection*{Phase 1 — Initial Lab Calibration (once)}
\begin{itemize}
  \item \textbf{Target-based, OpenCV:} Checkerboard-based initialization to estimate intrinsic/extrinsic parameters.
  \item \textbf{Global refinement:} Bundle adjustment over the collected images points to improve estimated parameters and obtain a consistent calibration.
  \item \textbf{Baseline:} Store the resulting calibration as the known-good reference for later comparison.
\end{itemize}

\subsection*{Phase 2 — Health-Check (periodic)}

\begin{itemize}
  \item \textbf{Trigger:} Fixed interval (e.g.\ every 3 minutes), temperature changes, or system restart.

  \item \textbf{Small image set (sampling):} 
  Periodically capture a small, recent image set during normal operation.

  \item \textbf{Parameter-based health metrics:}
  \begin{itemize}
    \item \emph{Intrinsic deviation:} Relative deviation of key intrinsic parameters (e.g.\ principal point, effective focal length, low-order distortion) compared to the reference (initial) calibration.
    \item \emph{Extrinsic deviation:} Change of estimated extrinsic parameters relative to the reference calibration.
    \item \emph{Parameter drift:} Normalized parameter change between consecutive health-check windows.
  \end{itemize}

  \item \textbf{Health score:} 
  Combine the normalized intrinsic and extrinsic deviations into a single health score.

  \item \textbf{Decision:} 
  If the health score exceeds a predefined threshold for $\geq 2$ consecutive health-check windows, the calibration is considered degraded and Phase~3 is triggered.
\end{itemize}

\subsection*{Phase 3 — Target-Free Online Recalibration}

\begin{itemize}
  \item \textbf{Larger image set:} 
  Collect a larger image set from recent normal operation to increase parameter stability.

  \item \textbf{Re-estimation scope:}
  \begin{itemize}
    \item Re-estimate intrinsic and extrinsic calibration parameters using the larger image set.
    \item Keep structural properties of the camera rig (e.g.\ baseline and physical layout) fixed.
  \end{itemize}

  \item \textbf{Method:} 
  Perform a LiFCal-based parameter estimation on the extended image set.

  \item \textbf{Commit rule:} 
  The updated calibration is adopted only if the resulting parameter deviations and health score improve compared to the previous calibration; otherwise, the update is discarded and retried later.
\end{itemize}
